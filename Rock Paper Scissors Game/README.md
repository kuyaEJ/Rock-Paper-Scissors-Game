# Final Project
## Requirements: 
Before you try to use this project make sure you have the requirements:
- Working Computer
- Python installed (Skip this step if using Ubuntu since it already has Python installed.)
- Basic knowledge about your Computer's file management and some of its software
- Some commands in command line
## Instructions:
To run the program follow the following instructions. 
  - Open command prompt
  - Copy the location of files downloaded from this project using your shortcut to copy and paste (CTRL + C and CTRL + V on Windows) 
  - Paste the file path where the following text says "filepathhere". 
```git
cd "filepathhere/Rock Paper Scissors Game"
```
  - Example: 
```git
cd "C:\Users\user02\Downloads\Rock Paper Scissors Game"
```
(The ```cd``` command navigates the current directory to the file path we provide. Don't forget the quotes! \" \" )
  - Now that the command line is in the directory of the project we can run the program with the command:
```git
python rps.py
```
- The program should open up a small window to play the game. Enjoy!

**Warning** \*\*Be sure not to delete/rename any of the images or the program will not run correctly.
Changing the directory or filepath of the images will be problematic as well
